### What's here

**[surtaal](https://github.com/kuanrdebesh/surtaal)** — A local audio studio for Indian classical and Bollywood practice: stem separation, vocal removal, pitch shift without tempo change, BPM detection. FastAPI + React + Electron.
*The decision:* run everything on the user's machine. Singers won't upload unreleased recordings to a cloud service, and a practice tool with a per-track cost gets used twice.

**[flexflow](https://github.com/kuanrdebesh/flexflow)** — A stretch planner that asks what you trained, then builds the pre- and post-session routine. Offline PWA.
*The decision:* organise by muscle group worked, not by routine name. People remember what they trained; they don't remember which routine they're supposed to be on.

**[Sargam-Trainer](https://github.com/kuanrdebesh/Sargam-Trainer)** — Raga practice with generated tones across eight ragas, in any Sa. Streamlit.
*The decision:* synthesise the notes instead of shipping samples. Any Sa, any tempo, no audio library to maintain.
